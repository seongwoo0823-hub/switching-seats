# 우리반 자리바꾸기 (PWA + 서버 기록 동기화 패키지)

이 패키지는 **PWA(앱 설치 및 오프라인 실행)** 와 **서버에 자리 배치 기록을 영구 저장/동기화**할 수 있도록 구성된 풀스택 패키지입니다.

## 1. 바로 실행하는 방법 (설치 패키지 없이 즉시 실행!)

Node.js 또는 Python 3 중 편한 환경 하나로 실행하세요.

### 방법 A: Node.js로 실행
```bash
node server.js
```

### 방법 B: Python 3로 실행
```bash
python3 server.py
```

실행 후 브라우저에서 **`http://localhost:3000`** 으로 접속하면 됩니다.

---

## 2. 주요 기능

1. **PWA 앱 설치 (`manifest.json` + `sw.js`)**
   - 상단바의 **[앱 설치]** 버튼을 누르거나 주소창 우측 설치 아이콘을 클릭해 PC/태블릿/스마트폰에 앱으로 설치할 수 있습니다.
   - 설치 후에는 인터넷 연결이 끊겨도 오프라인 캐시로 작동합니다.

2. **서버 기록 저장 및 여러 기기 간 동기화 (`/api/sync/:room`)**
   - **[설정] → [서버 저장 및 클라우드 동기화]** 에서 **학급 동기화 코드(예: `2026-5-2`)** 를 입력합니다.
   - `server.js` 또는 `server.py`를 통해 접속한 경우 서버 주소를 비워두어도 자동으로 현재 서버(`/api/sync`)에 저장됩니다.
   - 외부 클라우드나 학교 서버에 배포한 경우 해당 서버 URL을 입력하면 교실 전자칠판과 교무실 PC에서 동일한 학급 명단·자리 기록·교환 사유 기록을 주고받을 수 있습니다.
   - 모든 서버 데이터는 `data/<학급코드>.json` 파일로 안전하게 저장됩니다.
